# Task 4 – Data Visualization and Storytelling

## 📌 Overview

This project is completed as part of the **Veda Technologies Data Analytics Internship – Task 4: Data Visualization and Storytelling**.

The objective of this task is to transform structured COVID-19 data into meaningful visualizations that communicate important trends, patterns, and insights clearly. The analysis was performed using **Microsoft Power BI**, focusing on COVID-19 cases, active cases, discharged/recovered cases, and deaths across different Indian states and zones.

Rather than simply creating charts, the visualizations are designed to answer specific analytical questions and make the data easier to understand for stakeholders.

## 🎯 Objective

The main objective of this project is to practice converting a structured dataset into a clear visual narrative by:

- Understanding COVID-19 case distribution
- Comparing cases across zones and states
- Analyzing active and discharged cases
- Examining death counts across regions
- Identifying differences in COVID-19 impact across zones
- Communicating findings through meaningful visualizations

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Data Analysis
- Interactive Charts
- COVID-19 Dataset

## 📊 Visualizations Created

### 1. Count of Deaths by Zones

This visualization compares the number of COVID-19 deaths across different zones.

**Purpose:**  
To understand how the number of reported deaths varies between different geographical zones.

**Key Question:**  
Which zones experienced a higher number of reported COVID-19 deaths?

---

### 2. Sum of Total Cases by Zone and State

This visualization presents the total COVID-19 cases across different zones and states.

**Purpose:**  
To compare the overall spread of COVID-19 across geographical regions and identify states contributing significantly to total cases.

**Key Question:**  
How were total COVID-19 cases distributed across zones and states?

---

### 3. Sum of Active and Discharged Cases

This visualization compares the number of active and discharged COVID-19 cases.

**Purpose:**  
To understand the overall status of reported COVID-19 cases and compare ongoing cases with cases that had been discharged/recovered.

**Key Question:**  
How do active cases compare with discharged cases in the dataset?

---

### 4. Sum of Deaths by State

This visualization compares reported COVID-19 deaths across individual states.

**Purpose:**  
To identify differences in reported deaths between states and understand which states had a comparatively higher impact.

**Key Question:**  
Which states recorded higher numbers of reported COVID-19 deaths?

---

### 5. Count of Active Cases by Zone

This visualization compares active COVID-19 cases across different zones.

**Purpose:**  
To understand the distribution of currently active cases across geographical zones represented in the dataset.

**Key Question:**  
Which zones had a higher concentration of active COVID-19 cases?

---
